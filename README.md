# Shiny's Token Aura Rings

## Features (v1.3.0)

- Any number of rings per token, added and removed in the config dialog, starting from zero rings
- Per ring: radius in scene distance units (e.g. ft), color, line width, line opacity, optional fill with its own fill opacity, and a GM only visibility toggle
- Collapsible ring cards laid out two per row in a bordered grid, with a scrollable list so Save and Cancel stay reachable no matter how many rings you add
- Live preview on the canvas while editing, before you save
- Configured via a button on the Token HUD
